What to do with it

  1. Install Sagito, if you have not already — the button below opens the App Store.
  2. Open it and go to the grown-up area, at the bottom of the home screen.
  3. To connect your families, choose Connect a family. For a card swap, open Explorer cards → Swap cards and paste it where it says Got a code?
  4. Paste the code and follow what it says.

On Android? Sagito is not on Google Play yet — it is with Google for review.

Codes run out. A code to connect lasts a day, and a swap or a gift three days, so if yours is refused as expired, just ask for another.

Is this safe?

A code carries only what it needs. A code to connect two families carries the family name the sender chose and the first names or nicknames of the members they chose to connect; a card swap code carries which card, and no names at all. Never an adult's name, never a location, never anything about how a child is getting on. A code only works for the family it was sent to, but it is ordinary text, so treat one like a note passed in the playground rather than a sealed envelope.
